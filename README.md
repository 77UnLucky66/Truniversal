# ⚡ QuickTranslate & Rewrite (Vibe-Coded Edition)

Минималистичный помощник для переводчиков и всех, кто работает с текстом на Windows. Висит в системном трее, вызывается по хоткею поверх любых окон, умеет быстро переводить (через обычный Google/DeepL или через ИИ) и перефразировать текст по вашим собственным промптам.

> **✨ Дисклеймер:** Этот проект на 100% создан методом **вайбкодинга (vibe-coded)** — от лица переводчика для переводчиков. Код написан при помощи ИИ, чтобы решить реальную рабочую боль с «пластиковым» машинным переводом и неудобным переключением между окнами. Он простой, работает как часы, но внутри могут встречаться забавные архитектурные решения.

## 🔥 Что умеет программа
- **Мгновенный захват текста:** Выделите текст в любом приложении (браузер, Word, CAT-тулза, мессенджер) и нажмите `Alt + Q` (настраивается).
- **Режим «Ленты» в мини-окне:** Не нужно закрывать окно после каждого перевода — выделяйте следующие абзацы, жмите хоткей, и новые карточки с переводом будут добавляться вниз списка.
- **Два режима работы:**
  - 🌐 **Обычный переводчик (без ИИ):** Быстрый перевод через бесплатный движок Google Translate без галлюцинаций.
  - 🤖 **ИИ-режим (Ollama / OpenAI / OpenRouter):** Перевод и рерайт по вашим кастомным системным промптам (например: *«Дай 3 варианта: разговорный, нейтральный и художественный»*).
- **Гибкие и понятные настройки:** Ползунки креативности (`Temperature`, `Top-P`) снабжены простыми человеческими пояснениями прямо в интерфейсе — не нужно быть программистом, чтобы настроить модель под техперевод или худлит.
- **Замена в 1 клик:** Кнопка быстрой подстановки готового перевода прямо на место выделенного текста.

## 🚀 Как скачать и запустить (для обычных пользователей)
Вам **не нужно** устанавливать Python или уметь программировать:
1. Перейдите в раздел **[Releases](ссылка_на_релизы_справа)** на этой странице.
2. Скачайте файл `Truniversal.exe` из последнего релиза.
3. Запустите его — в системном трее (справа внизу у часов) появится иконка программы.
   *(Примечание: при первом запуске Windows SmartScreen может предупредить о неизвестном издателе. Нажмите «Подробнее» -> «Выполнить в любом случае»).*

## 🛠️ Запуск из исходников (для разработчиков)
Если вы хотите поковыряться в коде или довайбкодить свои фичи:
1. Склонируйте репозиторий: `git clone https://github.com/ваш-ник/название-репо.git`
2. Установите зависимости: `pip install PyQt6 keyboard pyperclip deep-translator requests`
3. Запустите: `python main.py`
