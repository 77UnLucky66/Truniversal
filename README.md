# Truniversal — интеллектуальный ассистент переводчика и редактор текста (Windows / PyQt6)

---

## 📖 О проекте

**Truniversal** — это лёгкое и быстрое Windows-приложение на базе **PyQt6**, работающее в фоновом режиме системного трея.

Выделяя текст в **любой** программе (браузере, VS Code, Word, Telegram, Slack, Notion, терминале или PDF-ридере) и нажимая настраиваемую глобальную горячую клавишу (по умолчанию `Alt+Q`), вы мгновенно вызываете мини-окно с результатами перевода или выполнения одного из быстрых действий искусственного интеллекта.

В отличие от стандартных переводчиков, Truniversal:

- **Сохраняет 100% данных вашего буфера обмена** (текст, изображения, файлы, форматирование RTF/HTML).
- **Поддерживает любые LLM-модели**: локальные через Ollama, облачные через OpenRouter, OpenAI, Custom API.
- **Хранит API-ключи в Windows Credential Manager** (без открытого текста в файлах конфигурации).
- **Позволяет выбирать из 14+ быстрых действий** (AI Quick Actions) в 1 клик или клавишами `1`..`9`.
- **Даёт возможность редактировать исходный текст и результат на лету**, генерировать несколько вариантов, визуально сравнивать diff с подсветкой изменений и безопасно вставлять отредактированный текст обратно в исходное приложение.

## 🚀 Ключевые возможности

### 1. Глобальный захват и 100% надёжность буфера обмена

- **Работа в любом окне**: перехват сочетания клавиш через Win32 API и библиотеку `keyboard`.
- **Полный снимок буфера (Full Snapshot)**: перед копированием приложение делает снимок всех форматов буфера Windows (`CF_UNICODETEXT`, `CF_DIB`/`CF_BITMAP`, `CF_HDROP` для файлов, `HTML Format`, `Rich Text Format` и др.).
- **Интеллектуальное восстановление**: после считывания выделенного текста буфер обмена восстанавливается в исходное состояние. Если пользователь успел скопировать что-то другое, срабатывает сверка `GetClipboardSequenceNumber`, предотвращая перезапись новых данных.
- **Отказоустойчивая цепочка копирования**: несколько методов эмуляции копирования (`Ctrl+Insert`, `Ctrl+C` через virtual keys, `Ctrl+C` через scan-коды) с настраиваемой задержкой и дебаунсом.

### 2. Два режима работы

- **🤖 Режим «ИИ» (AI Assistant)**:
  - Подключение к локальным или облачным LLM через единый OpenAI-совместимый REST API.
  - Поддержка параметров генерации: `temperature`, `top_p`, таймауты, кастомные HTTP-заголовки.
  - Проверка связи с сервером в один клик и автоматическая загрузка списка доступных моделей.
- **⚡ Режим «Обычный» (Standard Translator)**:
  - Быстрый машинный перевод через **Google Translate** (без необходимости API-ключа) или **DeepL API**.
  - Моментальный отклик для повседневного чтения иностранного текста.

### 3. Расширенная система AI-профилей

- **Неограниченное количество профилей**: создавайте отдельные профили для локальной Ollama (Llama 3, Mistral, Qwen, Gemma), облачного OpenRouter (Claude 3.5 Sonnet, GPT-4o), официального OpenAI или кастомных эндпоинтов.
- **Управление профилями**: создание, копирование (дублирование со всеми параметрами), удаление, переименование и тестирование в окне настроек.
- **Безопасность корпоративного уровня**: API-ключи сохраняются напрямую в защищённое системное хранилище **Windows Credential Manager** (библиотека `keyring`), маскируются в интерфейсе (`sk-••••abcd`) и никогда не сохраняются в открытом виде в `config.json` и не выводятся в диагностические логи.

### 4. Мультиязычность и умное автоопределение (16 языков)

- **16 предустановленных языков**: Русский, Английский, Немецкий, Французский, Испанский, Итальянский, Португальский, Польский, Украинский, Китайский (упрощённый), Японский, Корейский, Турецкий, Нидерландский, Арабский, Хинди.
- **Продвинутый детектор языка**: распознавание алфавитов и письменностей (Cyrillic, Latin, CJK Han, Hangul, Hiragana/Katakana, Arabic, Devanagari) со словарными маркерами и эвристикой.
- **Auto-Flip (двунаправленный автоперевод)**: если выделенный текст уже написан на целевом языке, Truniversal автоматически переводит его на запасной язык (fallback) или язык оригинала.
- **Ручной реверс `[⇄]`**: мгновенная смена направления перевода прямо на карточке.

### 5. AI Quick Actions — быстрые действия над текстом

Мгновенное применение специализированных промптов без ручного ввода:

1. 🌐 **Перевести (литературный)** — художественный и связный перевод.
2. 💼 **Перевести (деловой / профессиональный)** — строгий корпоративный стиль.
3. 💬 **Перевести (разговорный)** — живой естественный язык и сленг.
4. ✍️ **Перефразировать** — сохранение смысла другими словами.
5. ✨ **Сделать естественнее** — сглаживание машинного оттенка фразы.
6. 🔍 **Исправить грамматику и пунктуацию** — исправление ошибок с сохранением структуры.
7. 🎨 **Улучшить стилистику** — повышение выразительности текста.
8. 👔 **Сделать более формальным** — подготовка к официальной переписке.
9. ☕ **Сделать более разговорным** — неформальный тон для чатов.
10. ✂️ **Сократить (summary)** — краткая выжимка сути без «воды».
11. 📖 **Расширить и дополнить** — развёрнутое изложение тезиса.
12. 💡 **Объяснить смысл простыми словами** — объяснение сложных терминов и фраз.
13. 🎲 **Предложить 3 альтернативных варианта** — три разных стилистических решения.
14. 🛠️ **Пользовательский промпт** — поле быстрого ввода своего запроса в шапке мини-окна.

- **Быстрый доступ**: закрепление избранных действий в виде кнопок-пилюль («pills») над лентой карточек, запуск действий цифровыми клавишами `1`..`9`.
- **Редактор действий**: настройка системных промптов, добавление собственных действий, сортировка вверх/вниз, дублирование.
- **Шаблонизация с переменными**:
  - `{target_lang}` — целевой язык;
  - `{source_lang}` — исходный язык;
  - `{text}` — выделенный фрагмент;
  - `{project_context}` — глобальный контекст текущего проекта (напр. _«Перевод технической документации»_);
  - `{glossary}` — словарь специальных терминов для точного перевода.

### 6. Улучшенное мини-окно и визуальный редактор (Этап 6)

- **Инлайн-редактирование источника `[✎ Исходник]`**: исправьте опечатку в исходном тексте прямо в карточке и нажмите `[▶ Повторить с этим текстом]` без повторного выделения в браузере.
- **Ручная правка результата `[✎ Ответ]`**: отредактируйте сгенерированный текст перед копированием или заменой (появляется бейдж `✎ изменено`).
- **Раздельные карточки вариантов**: при генерации альтернатив Truniversal разделяет варианты на независимые блоки — каждый со своей кнопкой `[Заменить в тексте]` и `[Скопировать]`.
- **Side-by-side & Diff сравнение `[🔍 Сравнить]`**: удобное сопоставление исходника и результата с пословной цветовой подсветкой добавленных и удалённых слов.
- **Безопасная замена в приложении-источнике `[Заменить в тексте]`**:
  - Проверка валидности дескриптора окна (`IsWindow`).
  - Фокусировка приложения-источника и автоматическая вставка.
  - Защита от вставки в устаревший контекст (предупреждение при задержке более 5 минут).
  - Защита от вставки в само окно Truniversal.
  - Автоматический fallback: если окно было закрыто, текст безопасно копируется в буфер с подсказкой.
- **Мгновенная отмена `[✕ Отмена]`**: прерывание долгого запроса к ИИ без зависания интерфейса.
- **Свободное изменение размеров**: окно плавно масштабируется от 480px до любого удобного размера и сохраняет позицию на экране.

## ⚙️ Установка и запуск из исходников

### Требования

- **ОС**: Windows 10 / 11 (64-bit)
- **Python**: 3.10, 3.11, 3.12 или 3.13

### Шаги установки

1. Клонируйте репозиторий:

   ```powershell
   git clone https://github.com/your-username/Truniversal.git
   cd Truniversal
   ```

2. Создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   ```

3. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

4. Запустите приложение:
   ```powershell
   python main.py
   ```

Приложение появится в системном трее Windows:

- **Клик ЛКМ** по иконке трея — открыть окно настроек «Комбайн».
- **Клик ПКМ** по иконке трея — контекстное меню (настройки, мини-окно, быстрое вкл/выкл хоткея, выход).
- **Горячая клавиша** (`Alt+Q`) — обработка выделенного текста в любом приложении.

> **Примечание**: для корректной работы глобального хоткея в окнах, запущенных от имени Администратора (например, PowerShell или диспетчер задач), само приложение Truniversal также должно быть запущено от имени Администратора (политика безопасности Windows UIPI).

## 📦 Сборка в один автономный `.exe` (PyInstaller)

Для сборки автономного исполняемого файла `Truniversal.exe` (не требующего установленного Python на целевом компьютере):

```powershell
# 1. Активируйте виртуальное окружение с установленными зависимостями
.\.venv\Scripts\activate

# 2. Выполните сборку по готовой спецификации
pyinstaller --clean Truniversal.spec
```

После завершения сборки готовый файл будет находиться в папке `dist/`:

```
dist/Truniversal.exe
```

- Сборка создаётся в режиме `--windowed` (без всплывающего чёрного окна консоли).
- Иконка `build_icon.ico` автоматически вшивается в ресурсы `.exe`.
- Файл настроек `config.json` автоматически создаётся в одной папке с `Truniversal.exe`, что позволяет переносить программу на USB-накопителе в портативном режиме.
