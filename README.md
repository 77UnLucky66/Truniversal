# Truniversal — помощник переводчика (Windows / PyQt6)

Фоновое приложение-помощник переводчика: живёт в системном трее, по глобальному
хоткею забирает выделенный в любом окне текст, переводит его (ИИ или обычный
переводчик) и показывает результат в компактном мини-окне.

## Архитектура (3 узла)

| Узел | Назначение |
|------|-----------|
| **Иконка в системном трее** | Приложение всегда работает в фоне; клик — настройки, ПКМ — меню |
| **Главное окно («Комбайн»)** | Настройки: модели, системные промпты, параметры генерации, хоткеи |
| **Мини-окно (Quick Popup)** | Карточки переводов по хоткею; только чтение и копирование, без поля ввода |

## Стек

- Python 3.10+
- PyQt6 (тёмная минималистичная тема на QSS)
- `keyboard`, `pyperclip` — глобальные хоткеи и буфер обмена
- `deep-translator` — режим «Обычный»: перевод через Google
- `requests` — режим «ИИ»: OpenAI-совместимый API (Ollama, OpenRouter, OpenAI)
- `config.json` — локальные настройки рядом с приложением

## Структура проекта (Шаг 1)

```
Truniversal/
├── main.py               # точка входа: трей, меню, программная иконка
├── config.py             # менеджер конфигурации (config.json)
├── styles.py             # тёмная QSS-тема и палитра + тёмный заголовок окон
├── hotkey_manager.py     # глобальный хоткей + захват выделения (keyboard → pyqtSignal)
├── settings_window.py    # окно настроек «Комбайн»: вкладки, промпты, хоткеи
├── mini_window.py        # мини-окно Quick Popup: лента карточек
├── translation_card.py   # карточка: «Думаю…», результат, ошибка, копирование
├── workers.py            # TranslationWorker(QThread): Google / OpenAI-совместимый API
├── test_config.py        # самопроверка менеджера конфигурации
├── smoke_test.py         # GUI smoke-тест в режиме offscreen (без реальных окон)
├── make_icon.py          # генерирует build_icon.ico для сборки .exe
├── diag_capture.py       # диагностика: какие способы эмуляции копирования работают

├── requirements.txt

```

## Запуск

```powershell
cd a:\Progs\Truniversal

# 1. (рекомендуется) виртуальное окружение
python -m venv .venv
.venv\Scripts\activate

# 2. зависимости
pip install -r requirements.txt

# 3. запуск
python main.py
```

Приложение появится в системном трее:

- **одиночный клик** по иконке — окно настроек;
- **правый клик** — меню: «Открыть настройки», «Открыть мини-окно», «Выход»;
- **глобальный хоткей** (по умолчанию `alt+q`): выделите текст в любом
  приложении и нажмите хоткей — откроется мини-окно с карточкой;
- **закрытие любого окна не завершает приложение** — оно остаётся в трее;
- **«Выход»** в меню трея — единственный способ завершить приложение.

> Захват текста: приложение сохраняет ваш буфер обмена, очищает его и
> пробует цепочку способов копирования (`Ctrl+Insert`, затем `Ctrl+C` двумя
> способами), пока в буфере не появится выделенный текст; после чего
> возвращает ваш буфер на место. Чтобы хоткей срабатывал в окнах, запущенных
> от администратора, само приложение тоже нужно запускать от администратора
> (ограничение Windows). Диагностика захвата на вашей машине: `python diag_capture.py`.

Самопроверка конфигурации: `python test_config.py`
GUI smoke-тест (Qt в режиме offscreen, окна не отображаются): `python smoke_test.py`

## Сборка в один .exe (PyInstaller)

```powershell
pip install pyinstaller
python make_icon.py        # создаёт build_icon.ico из программной иконки
pyinstaller --noconfirm --onefile --windowed --name Truniversal --icon build_icon.ico main.py
```

Готовый файл: `dist\Truniversal.exe` — один файл, без чёрного окна консоли.
`config.json` создаётся рядом с .exe, поэтому папку `dist` можно переносить
целиком. Тесты/диагностика в exe не попадают — только само приложение.

## config.json — ключи настроек

| Ключ | Дефолт | Описание |
|------|--------|----------|
| `hotkey` | `alt+q` | Глобальный хоткей мини-окна (синтаксис библиотеки `keyboard`) |
| `mode` | `ai` | Режим перевода: `ai` (ИИ) или `standard` (обычный переводчик) |
| `standard_engine` | `google` | Движок обычного режима: `google` / `deepl` |
| `target_lang` | `ru` | Целевой язык перевода |
| `api_url` | `http://localhost:11434/v1/chat/completions` | OpenAI-совместимый эндпоинт (дефолт — локальная Ollama) |
| `api_key` | `""` | API-ключ (для локальной Ollama не нужен) |
| `deepl_api_key` | `""` | Ключ движка DeepL (для режима «Обычный») |
| `model_name` | `llama3` | Имя модели |
| `temperature` | `0.3` | «Креативность» генерации (0.0–2.0) |
| `top_p` | `0.9` | Nucleus sampling (0.0–1.0) |
| `active_prompt_name` | `Живой перевод` | Активный пресет системного промпта |
| `prompts` | 3 пресета | Словарь «имя пресета → системный промпт» |

> В текстах промптов можно использовать плейсхолдер `{target_lang}` — при
> отправке запроса он подменяется значением настройки `target_lang`.
>
> Повреждённый `config.json` не роняет приложение: файл бэкапится в
> `config.json.bak`, вместо него создаётся конфиг с дефолтами.

## Что сделано (Шаги 1–2)

Шаг 1:
- `config.py` — создание/чтение/сохранение `config.json`, дефолты, мягкая
  валидация, восстановление повреждённого файла
- `main.py` — иконка в трее, программно сгенерированная иконка (без .png),
  меню «Открыть настройки» / «Открыть мини-окно» / «Выход»
- Закрытие окон не завершает приложение (живёт в трее)
- Тёмная QSS-тема, тёмные заголовки окон

Шаг 2:
- `hotkey_manager.py` — глобальный хоткей (`keyboard`, отдельный поток),
  захват выделения: сохранение+очистка буфера → пауза 0.1 с → сброс
  модификаторов → цепочка способов копирования (`Ctrl+Insert` → `Ctrl+C`
  (vk) → `Ctrl+C` (scan) → `Esc`+`Ctrl+C`; разные приложения понимают
  разные хоткеи) → чтение буфера → возврат буфера; текст уходит в GUI
  строго через `pyqtSignal`
- `mini_window.py` + `translation_card.py` — мини-окно Quick Popup: всегда
  поверх всех окон, поля ввода нет, лента карточек в `QScrollArea`, плавный
  скролл к новой карточке, открытие у курсора/в правом нижнем углу, панель
  «ИИ / Обычный» + пресет промпта + «Очистить история», кнопка «Скопировать»
  с подтверждением «Скопировано ✓»
Шаг 3:
- `workers.py` (`TranslationWorker(QThread)`) — реальный перевод в фоновом
  потоке: «Обычный» — GoogleTranslator, «ИИ» — POST на `api_url` (Ollama /
  OpenRouter / OpenAI) с активным промптом, `model_name`, `temperature`,
  `top_p`; в карточке крутится «Думаю…», ответ или понятная ошибка появляются
  прямо в карточке
- Автоопределение ru↔en в ОБОИХ режимах: если текст уже на целевом языке,
  направление автоматически переворачивается (англ. → рус. и наоборот)

Шаг 4:
- `settings_window.py` — полноценное окно «Комбайн» с тремя вкладками:
  «Модели и Параметры ИИ» (адрес API с быстрыми пресетами Ollama /
  OpenRouter / OpenAI, ключ, модель + загрузка списка из Ollama, ползунки
  Temperature / Top-P с подробными подсказками простым языком), «Мои
  Промпты» (список пресетов, редактор, добавление/удаление, шпаргалка),
  «Хоткеи и Обычный переводчик» (запись сочетания кнопкой, движок
  Google / DeepL, целевой язык). Смена хоткея перерегистрируется на лету;
  промпты обновляют мини-окно без перезапуска

Шаг 5:
- Кнопки «Повторить» и «Заменить в тексте» на каждой карточке: «Повторить»
  перегенерирует перевод (работает и после ошибки); «Заменить в тексте»
  прячет окно, возвращает фокус в ваше приложение и вставляет результат
  на место выделения (Ctrl+V, vk-инъекция)
- Сборка в один .exe без консоли (PyInstaller); `config.json` живёт рядом
  с .exe (поддержка `sys.frozen`), `print()` безопасен при `--windowed`

## Дальнейшие шаги (план)
